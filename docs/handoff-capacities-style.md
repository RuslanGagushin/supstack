# Handoff Spec: стиль приложения Capacities → Supstack

Источник: веб-приложение app.capacities.io (desktop, 1440×900, светлая тема). Экраны: список объектов (All), карточки, сайдбар, превью заметки (peek), редактор с кодом, цитатой и таблицей. Значения сняты через DevTools 27.11.2026. Корневой шрифт у них 15.5px, поэтому все rem дают дробные пиксели: ниже они округлены.

## Overview

Что делает Capacities узнаваемым, по убыванию заметности:

1. **Страница как лист на столе.** Сайдбар лежит прямо на тёплом фоне без границы, а основная область — белая карточка с отступом 8px от краёв окна, скруглением 12px, рамкой 1px и почти невидимой многослойной тенью. У нас сейчас три колонки на одном белом листе с линиями между ними.
2. **Монохромный интерфейс.** Главная кнопка тёмно-серая (`#454447`), а не синяя. Акцентного цвета у интерфейса почти нет: цвет есть только у контента (иконки типов, теги, код).
3. **Иконки в цветных плитках-сквиклах** (radius 32%, рамка 0.5px того же тона) у типов объектов в сайдбаре, на карточках и в заголовке заметки.
4. **Текст заметки крупнее интерфейса:** 15.5px против 13px в интерфейсе. У нас заметка 14px, почти как интерфейс.
5. **Мягкая геометрия:** кнопки и поля 12px, карточки 12px, превью 16px, строки меню 8px. Рамки у чипов и плиток 0.5px.
6. **Тени в три слоя с прозрачностью 1–5%.** Объём есть, но тень не видна.

У нас уже совпадает: Inter, тёплые серые, жирный заголовок около 30px, трекинг −0.025em, длительности 200ms.

## Layout

```
┌ окно ─────────────────────────────────────────────────────────────┐ фон --bg (#fbfaf9)
│ ⌄ Vault      ◧ │ ‹ › ▣ Code  +                                 ◨ │ ← хром 42px, без фона
│ ┌───────────┐  │ ┌───────────────────────────────────────────────┐ │
│ │ + New     │  │ │ ▣ Code                          ⌕ ⋯  [+ New ▾]│ │ ← карточка --win
│ └───────────┘  │ │  Overview  [All]                     2 ⌄ ⇅ ▤ │ │   r 12, 1px --line
│ ▦ Calendar     │ │ ┌──────────┐ ┌──────────┐                     │ │   тень --shadow-sheet
│ ◎ Tasks        │ │ │ ▣ Coding │ │ ▣ Coding │                     │ │
│                │ │ │ Title    │ │ Title    │                     │ │
│ Object Types   │ │ │ tags     │ │ tags     │                     │ │
│ ▣ Code   ◀ sel │ │ └──────────┘ └──────────┘                     │ │
│                │ └───────────────────────────────────────────────┘ │
└────────────────┴───────────────────────────────────────────────────┘
  сайдбар 240px,     inset 8px справа и снизу, 0 слева (сайдбар уже даёт отступ)
  без border-right
```

- Хром окна (вкладки и навигация) **над** карточкой на фоне, высота 42px (у нас `--header-height` 40, его и оставляем).
- Карточка: `margin: 0 var(--sp-8) var(--sp-8) 0`, `border-radius: var(--r-l)` (если введём 12, см. токены), `border: 1px solid var(--line)`, `box-shadow: var(--shadow-sheet)`.
- Если в карточке две колонки (список и заметка), между ними остаётся хэрлайн `--line`, как сейчас.
- **Телефон (< 820px):** карточки нет, страница во весь экран, как сейчас. Inset на маленьком экране съедает место.
- **Тёмная тема:** фон `--bg` #17181a, карточка `--win` #1c1d1f. Разница слабая, поэтому рамка обязательна; тень почти не видна, это нормально.

### Тени (все от `--shade`, у них чёрный)

| Наш токен | Capacities | Новое значение |
|---|---|---|
| **new** `--shadow-sheet` | `--shadow-sm` | `0 2px 3px rgb(0 0 0 / .4%), 0 4px 9px rgb(0 0 0 / 1%), 0 8px 12px rgb(0 0 0 / .4%)` |
| `--shadow-1` | `--shadow-xs` | `0 1px 2px …/.4%, 0 2px 4px …/1.2%, 0 3px 6px …/.4%` + оставить 1px контур для сегмента |
| `--shadow-2` | `--shadow-md` | `0 4px 7px …/1.2%, 0 7px 14px …/2.4%, 0 14px 20px …/1.2%` |
| `--shadow-3` | `--shadow-xl` | `0 8px 14px …/2%, 0 14px 28px …/4%, 0 28px 40px …/2%` + рамка 1px `--line` у меню |
| `--shadow-4` | `--shadow-3xl` | `0 16px 28px …/3%, 0 28px 56px …/6%, 0 56px 80px …/3%` |

Тени у них почти не видны, поэтому **меню и поповеры обязательно с рамкой 1px `--line`**: края видны по рамке, а тень даёт только ощущение подъёма. В тёмной теме проценты ×3 (через `--shade` и отдельные переменные).

| Ширина | Поведение |

| 820–1100px | То же, inset 6px (`--sp-6`) |

## Edge Cases

- **Тёмная тема:** лист и фон различаются на 2–3% яркости. Без рамки лист пропадёт, поэтому рамка 1px `--line` обязательна.
- **Окно Tauri без системной рамки (macOS):** inset 8px должен совпасть с отступом светофора; отступ сверху задаёт хром 40px.
- **Высокая плотность (Windows 100%):** 0.5px рамки округляются до 1px, плитки становятся темнее по краю. Допустимо.
- **Тесты:** `tests/typography.test.mjs` ловит новый размер текста (п. 4); `tests/architecture.test.mjs` — новые числа вне `base.css`. Все новые значения — переменные.
- **Контраст:** после смены `--bg` на #fbfaf9 пересчитать `--faint` на фоне (станет лучше, не хуже) и `--line` против фона (#e6e5e3 на #fbfaf9 ≈ 1.2:1, это декоративная линия, AA не требуется).

## Accessibility Notes

- Монохромная главная кнопка (п. 8): тёмный #454447 с текстом #f5f4f3 даёт около 9:1 — проходит. Фокус остаётся синим `--ring`, иначе фокус на тёмной кнопке теряется.
- Плитки иконок `aria-hidden`; смысл несёт текст строки.
- Убирая линии между сайдбаром и листом, проверить в Windows High Contrast: у листа есть рамка, граница видна.
- Текст заметки 15px / 1.55 улучшает читаемость; ширину колонки держать ≤ 75–80 символов.

## Порядок внедрения

1. **Тени и скругления** (`base.css`): переменные, без изменения разметки. Сразу видно, риск минимальный.
2. **Лист на фоне + сайдбар без линий + фон #fbfaf9.** Главный эффект.
3. **Плитки иконок.**
4. **Текст заметки 15px.** Сначала обновить spec UI-20 и тест.
5. **Главная кнопка** — отдельное продуктовое решение.
