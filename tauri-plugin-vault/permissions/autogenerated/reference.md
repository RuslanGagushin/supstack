## Default Permission

Pick a vault folder, then list, read, write and delete files inside it, watch it for changes, and sync it with a git remote.

#### This default permission set includes the following:

- `allow-pick`
- `allow-list`
- `allow-read`
- `allow-write`
- `allow-remove`
- `allow-remove-dir`
- `allow-list-dir`
- `allow-exists`
- `allow-git-sync`
- `allow-git-info`
- `allow-git-save-settings`
- `allow-watch`
- `allow-unwatch`
- `allow-take-shared`
